# Arbitrary Precision Calculator (APC) – Using C

##  Project Overview
The Arbitrary Precision Calculator (APC) is a C-based implementation designed to perform arithmetic operations on very large integers that exceed the standard data type limits. 

This project demonstrates dynamic memory handling, linked list implementation, and modular programming in C.

##  Objectives
- Perform addition, subtraction, multiplication, and division on large integers
- Overcome limitations of built-in data types
- Implement digit-by-digit arithmetic using linked lists

##  Technologies Used
- C Programming
- GCC Compiler
- Makefile
- Linked List Data Structure

##  Core Concepts
- Dynamic Memory Allocation
- Pointer Manipulation
- File Handling (if used)
- Modular Programming
- Custom Data Structures
